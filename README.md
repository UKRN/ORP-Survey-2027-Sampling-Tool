# ORP Survey 2027 Sampling Tool

## Overview
This tool has been created for the UKRN Open Research Programme Survey 2027. It allows UK institutions to generate a random sample that is representative across disciplines and career stages using institutional HESA (Higher Education Statistics Agency) data. 

## Running via Shinylive
This tool is configured to run entirely in the browser using Shinylive (Schloerke et al., 2026).
